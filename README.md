# 📝 Notes App

A simple and responsive Notes App built using **HTML**, **CSS**, and **JavaScript**. Create, edit, save, and delete notes with an intuitive interface. Notes are automatically stored in the browser using Local Storage, so they remain available even after refreshing or reopening the application.

---

## 🌐 Live Demo

🚀 [Launch Notes App](https://shoaibakhtar321.github.io/notes-app/)

---

## ✨ Features

- 📝 Create new notes
- 💾 Automatically save notes using Local Storage
- ✏️ Edit existing notes
- 🗑️ Delete notes
- ⌨️ Keyboard shortcuts for improved productivity
- ✅ Input validation (prevents creating notes with an empty title, alert messages)
- 🔄 Dynamic Edit/Save button functionality
- 🎯 Active note highlighting for better navigation
- 📱 Responsive and modern user interface

---

## 🚀 Getting Started

1. Clone the repository.

```bash
git clone https://github.com/shoaibakhtar321/notes-app.git
```

2. Open the project folder.

3. Open `index.html` in your preferred web browser.
